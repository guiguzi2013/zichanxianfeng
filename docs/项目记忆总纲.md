29. **自研 QCC 三大工作流（2026-09-01 用户确认，核心架构）**：官方 SKILL(企业画像速览/诉讼风险评估/债务清偿能力评估)是"全量豪华版"太贵(全钻 91-211 积分)；**自研精简工作流，只调需要的接口，多工作流协作共享缓存不重复调用**（工具级共享缓存 `tool:{tool}:{company}` 24h 内全站复用）。对应网站三大功能：

     - 涉案：**`get_case_filing_info`(3，案号/案由/立案日期/原被告，最契合"只要案号简述")** + `get_judicial_documents`(3，案由/裁判结果/涉案金额) + 风险扫描 `get_company_risk_scan`(5) 分诊→命中才钻 失信/被执行/限高/终本/股权冻结(各3)
     - ≈ 20-40 积分（2-4 元）
   - **② 财产线索**（先扫再钻，查很多）：企业基本信息 + 股东 + 知产(可拍卖变现) + 涉案(重点：企业作为**原告**可能胜诉产生的**未来债权**) + 矿权/林权/经营权等一切可变现权益

50. **融资租赁债权知识（2026-09-04 用户传授，知识库已入库）**：融资租赁两种形式——**直租**（出租方按承租方选定出卖人/设备出资购买，租给承租方用、收租金；承租方欠租违约 → 出租方/受让人持应收租金债权，可主张全部未付租金或解除合同收回租赁物，民法典第735/745/752条）与**售后回租**（承租方将自有设备卖给出租方取得资金再租回使用，租金实质=本金摊还+租息，本质类似设备抵押融资，司法常按借贷处理）。对不良债权：此类"抵押物"是**设备（租赁物）**，非房产。**平台处理规则（用户拍板）**：①识别=输入/判决书/Excel 含"融资租赁/售后回租/回租/融资租赁合同"字样；②有房产抵押 → 按正常债权处理（照常估值/出报告，抵押物栏名称不变）；③无房产+识别出融资租赁 → **视同有抵押物**、可尽调出报告，但**不做设备估价、不写覆盖率**；抵押物区块有设备清单就列清单，没有就写"设备租赁"；④无房产且识别不出融资租赁 → 抵押物缺失，不予尽调。落地：extractor 识别与完整度豁免、tasks 校验豁免、_node4/_node6 报告豁免、材料识别提取字段（债权人/利息计算方式/是否胜诉/债权类型）。
51. **施工汇报只进对话框，不进产品（2026-09-05 用户强调，铁律；与第48条互补：48讲"哪些信息不出现在用户界面"，本条讲"哪些沟通只走对话框"）**：用户原话——"网站是给其他人看的，不是给我看的；你想跟我表达什么在这个对话框里表达就可以，没必要放到网站上；不要在项目里告诉我你做了什么、没做了什么、什么原因没做"。**网站/App 界面=给使用者的成品，不是给老板的施工日志**：
   - 所有"我做了什么 / 没做什么 / 什么原因没做 / 为什么抓不到 / 下一步计划 / 数据从哪来"的解释性内容，**一律只在本对话或后台管理界面与老板沟通**，禁止做成界面文案/提示条/Alert/占位说明展示给使用者
   - 尤其禁止向使用者解释数据缺失原因（如"阿里资产详情需登录查看""原文有内容但我们抓不到""需要登录才能看完整"）——这类话是施工方对老板的解释，对使用者是噪音且暴露平台不完整
   - **写任何界面文案前自问**：这句话是给使用者用的（功能说明/风险提示/操作引导），还是向老板汇报的（解释/原因/过程/计划）？后者→不放界面，放对话框
   - **违反实例（2026-09-05）**：详情页"阿里资产详情需登录查看…"提示被老板两次圈出（使用者登录后看到的仍是同样字段，该提示无信息价值）→ 已删；同类已清理：HomePage"暂无数据请在管理后台录入"、工具页"新增N次调用/缓存命中M次/删除N条缓存"内部统计、企查查Demo 路由整页、页脚数据来源含"企查查"等

## 三、业务核心规则（一句话）

| 规则 | 内容 |
|---|---|
| 计息 | 计到报告当日；①截止日利息+LPR(3.45%)续算 ②判决书精确 ③无利息金额但有逾期起始时间→LPR×逾期至今粗算(注明"按LPR估算"，没有逾期就算了) ④无信息用录入值 |
| 覆盖 | 覆盖率=本息÷抵押物估值；≥100%覆盖（好事），<100%未覆盖（处置后可能倒找债务人钱）|
| 评级 | >150%★★★★★ / 100-150%★★★★ / 70-100%★★★ / 40-70%★★ / <40%★ |
| 估值 | 仅工业土地厂房(成本法=土地出让价+建安×折旧)与商业房产(市场价取最低价)；不做住宅估价 |
| 处置 | 拍卖/以物抵债/其他并列展示；未覆盖时提示退还问题；以物抵债无需其他债权人同意 |
| 法律 | 只引用知识库真实法规；禁止编造；"依据《XX法》（文号）" |
| 代偿 | 担保公司替债务人还款后成为债权人（追偿权），可转让该债权；金额构成=代偿金额+逾期担保费+滞纳金+垫付费用 |
