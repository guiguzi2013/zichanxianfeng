## 一、快速开始（香港服务器 · 临时展示 · 免备案）

```bash
# 1) 本机构建最新前端（Windows）：
cd frontend && npm run build

# 2) 上传整个项目（dist 一起带上；.venv/node_modules 可不上传，会被 .dockerignore 忽略）
scp -r zichanxianfeng root@<香港IP>:/opt/

# 3) 服务器上执行（装 Docker → 建 .env → 构建镜像 → 启动）
sudo bash /opt/zichanxianfeng/deploy/setup.sh

# 4) 编辑密钥后再次执行 setup.sh（首次只生成 .env 并退出）
vim /opt/zichanxianfeng/deploy/.env    # SECRET_KEY 用 openssl rand -hex 32
sudo bash /opt/zichanxianfeng/deploy/setup.sh
```

访问 `http://<香港IP>:8000`，健康检查 `http://<IP>:8000/api/health`。

**香港服务器不需要 ICP 备案**（机房在境外）；仅国内机房需要。此阶段用 IP + 8000 端口访问即可。

### 域名 nplcn.cn 上线（建议尽早做）

1. **域名实名**：.cn 域名必须在注册商完成实名认证（个人/企业主体），否则会被暂停解析——阿里云控制台"域名"→ nplcn.cn → 实名认证，立即提交（约 1-3 个工作日审核）。
2. **解析**：拿到香港服务器 IP 后加记录（阿里云云解析）：
   - `A` 记录：`@` → 香港服务器 IP
   - `A` 记录：`www` → 香港服务器 IP（可选）
3. **访问**：`http://nplcn.cn:8000`（未上 HTTPS 前带端口）。
4. 将来迁回国内正式上线：nplcn.cn 不含 china 字样，备案顺畅；备案通过后 nginx + 80/443 + HTTPS（见第五节）。

## 三、内存纪律（2核4G 服务器必须遵守）

抓取会起 Chromium headless（单个约 200-400MB）。**不要同时并发跑多个同步任务**：

- 后台「同步京东/阿里/AMC」逐个点、等一个完成再点下一个
- 浏览器封装已做「优先系统 Chrome、失败自动回退自带 Chromium」，失败只占一次启动开销
- 4G 下若需长期自动抓取，建议加 2G swap：
  ```bash
  fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
  echo '/swapfile none swap sw 0 0' >> /etc/fstab
  ```

## 四、数据迁移

### 4.1 把本机（Windows）现有数据带到服务器
本机 `backend/data/`（app.db + uploads + pdf）是全部业务数据，打包上传到服务器后**导入卷**：

```bash
# 本机打包（在项目根）：
tar 可用 WSL/git-bash；或直接复制 data 目录上传后：
scp -r backend/data root@<IP>:/tmp/zxf-data/

# 服务器：先别急着起服务，把数据灌进命名卷（服务没起时卷不存在，先 up 一次建卷再停）
cd /opt/zichanxianfeng
docker compose -f deploy/docker-compose.yml up -d     # 建卷
docker compose -f deploy/docker-compose.yml down      # 停容器（卷保留）
# 把 data 覆盖进卷
docker run --rm -v zxf-data:/data -v /tmp/zxf-data:/src alpine sh -c \
  'cp -a /src/. /data/'
docker compose -f deploy/docker-compose.yml up -d     # 再启动
```

> 注意：拷贝前先停容器避免 SQLite 写冲突；上传/拷贝过程中不要启动服务。

### 4.2 从香港迁回国内（正式上线）
数据 100% 在 `zxf-data` 卷，换机 = 搬卷：

```bash
# 旧机备份
docker run --rm -v zxf-data:/data -v $PWD:/out alpine tar czf /out/zxf-data.tgz -C /data .
# 新机（国内服务器，同代码同 compose）：
#   1) 建卷后停容器 → tar 解压进卷（同上 4.1）
#   2) 配置域名 → ICP 备案 → nginx + HTTPS（见下节）
```

**为什么可平滑迁回国内**：
- 无任何香港/IP/域名硬编码（路径全部相对、config 全环境变量化、数据单目录）
- 浏览器启动自动回退（不依赖 Windows Chrome）
- 端口/密钥/LLM 全在 `deploy/.env`，换机只改 .env

## 五、正式上线（国内服务器 · 备案后 · 可选 nginx+HTTPS）

1. **ICP 备案**：国内机房绑域名必须备案（阿里云/腾讯云控制台提交，约 1-2 周）。备案期间可用 IP 访问。
2. **域名解析**：A 记录 → 国内服务器 IP。
3. **HTTPS**：宿主机 nginx 或 compose 加 nginx 服务，配置见 `deploy/nginx.conf`（反代 127.0.0.1:8000，certbot 签证书）。
   ```bash
   apt-get install -y nginx certbot python3-certbot-nginx
   cp deploy/nginx.conf /etc/nginx/conf.d/zxf.conf   # 改 server_name 为域名
   certbot --nginx -d your.domain.com
   ```
4. **安全项**：`.env` 换随机 SECRET_KEY；删默认账号或改密码；开自动快照（数据在单卷/单盘）。

## 八、国内网络构建加速（迁回国内/或本机网络访问不了 Docker Hub 时）

```bash
# Docker 拉取 python 镜像 / chromium 需访问 Docker Hub；国内服务器/网络需配镜像加速：
# 方式一：改 /etc/docker/daemon.json 后用阿里云/腾讯云容器镜像加速器
cat > /etc/docker/daemon.json <<'EOF'
{ "registry-mirrors": ["https://docker.m.daocloud.io", "https://dockerproxy.com"] }
EOF
systemctl restart docker
# 方式二：构建时临时用代理（如已有 HTTP 代理）
# 注：chromium 由 playwright 从 https://cdn.playwright.dev 下载（境外），国内服务器若超时：
export PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright
docker compose -f deploy/docker-compose.yml build
```
