# 债权尽调维度清单（设计文档）

> 本文档定义"智能尽调"对一个债权进行尽调时覆盖的全部维度，是尽调引擎与报告生成的设计依据。
> 更新日期：2026-08-23 ｜ 与《技术需求文档》5.4 九版块报告衔接。

## 〇、平台宗旨与边界（最高原则，一切设计不得偏离）

### 平台宗旨
为不良资产从业者（资管公司）和个人投资者提供债权尽调服务，节约其从海量债权中筛选、评估、决策的时间与精力。

### 产品本质（价值所在）
用户本身能完成网站所有功能、甚至能写出同等报告，但需一周甚至更久——平台把"一周的尽调压缩到几分钟"，帮用户省时间；展示的一切都是参考，不给用户拿主意。

### 平台边界（明确）
1. **不做债权估值、不做买入决策** —— 买不买是用户自己的事，平台不负责；
2. **只做抵押物评估** —— 作为处置方案的依据，不是债权定价；
3. **尽调 = 事实呈现 + 处置方案 + 周期研判 + 法律风险意见**，供用户参考；
4. **利润公式（变现价−买债价+费用+资金成本）只是业务背景**（用户自己算），不在网站展示。

### 尽调输出核心内容
- 债权事实：本息、债务人、抵押物、司法状态；
- 抵押物评估：估值区间 + 覆盖本息判断；
- 处置方案：上拍 / 以物抵债 / 其他路径，含预计价格 / 周期 / 成功率（**多路径并列对比，不替用户决策**——形式 A，2026-08-23 用户确认）；
- 周期研判：含执行异议拉长的风险；
- 法律风险意见：引用知识库法条。

## 一、核心原则

1. **围绕"用户决策五问"组织**（技术需求文档 1.4）：抵押物足值？轮候查封？执行/清场难度？能否执行下去？以物抵债可行？
2. **本息可算**：有判决书→精确；无判决书→本金 + LPR 估算，标注依据。
3. **覆盖可判**：抵押物估值 vs 本息合计 → 能否覆盖（注意超额部分退还债务人）。
4. **数据是证据不是目的**：严禁空话，每项结论有事实依据；查不到的标"⚠️ 需人工补充"。
5. **用户可补充迭代**：补充材料 → 更新对应版块 → 生成新版本报告（版本+1，可回退）。
6. **法律依据入知识库**：涉及法条全部沉淀知识库，报告引用时自动匹配。

## 二、尽调维度（11 大类）

### 1. 债权基本信息（用户输入/提取）
| 字段 | 必填 | 说明 |
|------|------|------|
| 债务人名称/类型 | ✅ | 企业/自然人，决定后续查询范围 |
| 本金 | ✅ | 欠款本金，一切测算的基础 |
| 案号/案由 | 视情况 | 有判决书则详细 |
| 挂牌价/买入价 | ❌ | **非必备**：AMC招商/个人债权可能无挂牌价，仅招商协商，标注"协商中" |
| 债权来源 | 视情况 | 银行/AMC/民间，影响追偿策略 |
| 债权状态 | ✅ | 未诉/诉讼中/已判决/执行中/终本，决定报告重点 |

### 2. 本息测算
- 有判决书：本金/期内利息/罚息/迟延履行金，精确合计到当前日期
- 无判决书：本金 + LPR 估算期内利息 + 逾期罚息（标注估算依据）
- 已清偿部分扣除
- **法律依据**：民间借贷 LPR 四倍上限（法释〔2020〕17号）；迟延履行金（民诉法260条 + 法释〔2014〕8号，日万分之一点七五）✅ 已入知识库

### 3. 债务人画像（企查查）
- 企业：工商登记、注册资本、股东、实控人、对外投资、股权穿透、经营状态、年报、变更记录（近期股权/法人变更→转移资产信号）
- 自然人：身份锚点交叉验证、名下企业（自然人简版）

### 4. 司法风险
- 被执行、失信、限高、终本、裁判文书、立案、开庭、股权冻结/质押、行政处罚、经营异常

### 5. 法律文书与法规
- 判决书/裁定书摘要（含"本院认为"）、相关法条、效力层级标记

### 6. 抵押物分析
| 项 | 内容 |
|----|------|
| 抵押物类型 | 房产/土地/设备/车辆/应收账款/林权矿权等 |
| 估值 | 工业类（土地/厂房）→ **成本法**：土地出让价 + 厂房建安造价×折旧（20年直线/残值5%，年4.75%）；非工业类（住宅/商铺/写字楼等）→ 市场价区间法；输出保守/中性/乐观三档；**不做债权估值** |
| 成本法参数 | 土地单价档位：沿海（含青岛/北京等 600~1200元/㎡）/ 内地（450~750）/ 未知（450~900 全国中值）；厂房造价：轻钢600~1000 / 重钢1000~1500 / 砖混800~1200 / 未知结构700~1100 元/㎡；建成年份缺失则不折旧并提示补充（来源：土地出让公告/建安造价参考/矿业权评估参数指导意见，数据精度后期按公示数据细化） |
| 覆盖率 | 估值 ÷ 本息合计 → 能否覆盖 |
| 轮候查封 | 是否首封、轮候后实际受偿率 |
| 超额返还 | 处置款超出债权部分退还债务人（民诉法解释508-510条）✅ 已入知识库 |
| 变现可行性 | 流动性、处置周期 |
| 清场难度 | 占用/租赁/唯一住房/划拨土地/案外人主张权利 |

### 7. 保证人/担保分析
- 保证方式（连带/一般）、保证期间是否经过、保证人资信与财产

### 8. 执行与受偿分析
- 执行障碍、清偿顺序（抵押优先/税款/职工债权）、受偿确定性
- **执行异议风险**：债务人/案外人可能提执行异议（民诉法232/234条，15日审查+复议+可能异议之诉，周期显著拉长）✅ 已入知识库

### 9. 处置建议（两条路径对比）
- 正常拍卖路径（预计价格/周期/成功率）
- 以物抵债路径（流拍后抵债/过户障碍/税费）
- 最坏兜底方案

### 10. 智能提醒（规则库 21 条）
- 司法/抵押物/执行/债权有效性/税费 五类风险提醒，只显示匹配项

### 11. 用户补充信息迭代
- 补充入口：判决书/评估报告/情况说明/实地走访
- 补充后自动更新对应版块 → 报告版本+1
- 历史版本可查看/回退
- 用户处置意见可加入，报告合并呈现

## 三、法律依据知识库（已收录相关）

| 法律/规定 | 关键条款 | 用途 |
|-----------|---------|------|
| 民间借贷规定（法释〔2020〕17号） | LPR四倍上限 | 本息测算红线 |
| 民诉法（2023修正） | 260条迟延履行金、232条执行行为异议、234条案外人异议 | 本息增量 + 执行异议 |
| 民诉法解释（2022修正） | 508-510条参与分配/超额返还、501条执行到期债权 | 受偿测算 + 应收款 |
| 迟延履行利息解释（法释〔2014〕8号） | 日万分之一点七五 | 迟延履行金计算 |
| 执行异议复议规定（法释〔2015〕10号） | 异议程序 | 执行异议流程 |
| 执行追加规定、公司法、九民纪要、民法典保证、拒执罪等 | 既有 | 追索路径 |
