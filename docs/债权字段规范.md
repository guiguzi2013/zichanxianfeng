# 资产先锋 · 债权字段规范（全站统一 schema）

> 依据：2026-08-30 用户提供四大 AMC 参考表（信达/长城/泰和/各大银行包）+ 网站功能需求整理。
> 用途：Excel 导入 / 手动录入 / 京东阿里抓取 / 尽调报告 全站字段统一规范。
> 最后更新：2026-08-30

## 一、核心必备字段（缺一不可，缺失直接导致尽调/核心功能无法完成）

| 序号 | 字段 | 代码字段名 | 依赖的网站功能 | 缺失后果 |
|---|---|---|---|---|
| 1 | 债务人名称 | `debtor_name` | 尽调主体、工商/司法/企查查查询、财产线索、搜索、报告标题 | 一切查询无从开展 |
| 2 | 债权本金 | `principal_cents` | 本息计算、覆盖规则、综合评级、情景分析 | 无本金无法计息/覆盖 |
| 3 | 债权利息 | `interest_cents` | 本息计算（本息合计）、覆盖规则、评级 | 只能 LPR 估算，覆盖失真 |
| 4 | 抵押物类型 | `collateral_type` | 抵押物评估、覆盖规则、处置方案、卡片展示 | 无法评估/判断覆盖 |
| 5 | 抵押物描述 | `collateral_desc` | 评估精度（成本法/市场价）、财产线索 | 评估只能粗估 |
| 6 | 担保方式 | `guaranty_type` | 追偿路径、处置方案、法律风险 | 无法判断优先受偿 |
| 7 | 保证人名称 | `guarantor` | 财产线索（第二追偿对象）、报告 | 漏追偿对象 |
| 8 | 司法状态 | `judicial_status` | 处置周期研判、执行回收版块 | 周期判断失准 |

## 四、利息推算规则（用户传授知识）

1. **利息约 7 年翻番**：利息/本金比值可粗估贷款年限，仅供内部校验，不展示用户。
2. **计息到报告当日，四种情形（按优先级）**：
   - ① 有利息截止日 → 截止日利息 + LPR(3.45%) 续算
   - ② 有判决书 → 按判决书精确算
   - ③ **无利息金额但有逾期起始时间** → LPR(3.45%)×逾期至今粗算，注明「按LPR估算」；没有逾期时间就算了，不硬造（2026-08-30 用户补充）
   - ④ 无任何信息 → 用录入利息，注明「计息至债权发布日」
3. 逾期起始时间来源：用户提供的情况介绍/描述中可能有（表中一般没有）。

## 五、与各来源的映射

- **Excel 导入**（`excel_parser.py` 表头映射）：债务人/借款人/主债务人/企业名称 → `debtor_name`；本金/本金余额/收购本金/剩余本金 → `principal`；利息/利息余额/收购利息 → `interest`；抵质押物情况 → `collateral_desc`；保证人/担保人 → `guarantor`；担保方式 → `guaranty_type`；诉讼情况 → `judicial_status`；地区 → `region`；资产包/批次 → `batch`；原/现债权人 → `original/current_creditor`；案号 → `case_no`
- **京东/阿里抓取**（`scrapers/`）：已按本规范输出 `short_title/debtor_name/claim_total/listing_price/auction_status/region/collateral_type/source_url`（抓取源为 C 端信息，深度字段需运营补录）
- **手动录入/管理后台**：按本规范字段录入
