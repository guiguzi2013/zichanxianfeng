- **起拍价 < 1 万元，或 折扣 < 1 折**（京东 discountRate 语义：0.689=0.689折，即起拍不到本金1成）→ 归捡漏

- 破产搜索是另一条线：标题含"破产"+起拍≤100万全收（现已改为只收债权类、实物剔除）

## 京东接口探测结论（probe_jd*.py 实测）
- `multiPaimaiStatus=2` → 全部 auctionStatus=2（已结束）条目，可抓
- `liupaiBuyAgain=1` → 京东"流拍可再买"（变卖模式，流拍后仍可按现价再买），
  页面标签"流拍可再买"是频道导航；详情正文可抓（长江银行询价公告 ~300 字、无表格）
- `keyword=破产` 全类目 → 破产资产拍卖（商铺/股权/设备/酒/翡翠/家具等大量实物）
- 类目 109 + labelSet 1033 = 债权转让/招商版块（AMC/银行挂拍）
