# 债权尽调输入字段设计（最终版）

> 定义用户选择/输入/上传债权时，系统需要抓取的字段、校验规则与补充机制。
> 更新日期：2026-08-23 ｜ 依据：技术需求文档 5.2/5.3 + 8 份真实债权表格（参考文档）字段统计 + 用户确认。

## 一、核心必填字段（缺一不可，否则无法尽调）

| 字段 | 别名（表头/文本识别） | 校验规则 |
|------|----------------------|---------|
| **债务人名称** | 债务人/借款人/债权项目/企业名称/债务企业 | 非空 |
| **本金** | 本金/债权本金/借款本金/贷款本金/本金余额/收购本金 | 非空且 > 0 |
| **抵押物** | 抵押物/抵质押物/抵押情况/抵押物情况描述 | 非空（文本即可） |

**校验行为**：
- 网站债权列表勾选：三字段齐全才可勾选；缺失则该行不可勾选，标注"待补充"
- 粘贴/上传文本：缺任一字段 → 提示"缺少重要信息无法尽调"并列出缺失项
- 不标红，用 **"待补充"** 标签提示（用户确认，避免刺眼）

## 二、重要字段（有则记录，缺失提示待补充但不阻止）

| 字段 | 别名 | 说明 |
|------|------|------|
| 利息 | 利息/债权利息/欠息/利息余额/应收利息 | 含计息基准日更好 |
| 担保人/保证人 | 保证人/担保人/保证人名称 | 可能多个 |
| 诉讼进度 | 诉讼进度/司法状态/诉讼状态 | 未诉/诉讼中/已判决/执行中/终本/破产 |
| 地区 | 地区/所在地/地级市 | 省-市 |
| 执行法院 | 执行法院/法院/受理法院 | |
| 抵押人 | 抵押人 | 抵押物登记人（可≠债务人） |
| 抵押物类型 | 抵押物类型/抵质押资产分类 | 住宅/商业/工业/土地/设备/应收账款 |
| 抵押物位置/面积/权证号 | 抵押物（地址、面积、权证） | 从描述中提取 |
| 案号/案由 | 案号/案由 | 有判决书则详细 |
| 保证方式/保证期间 | 担保方式/保证期间 | 连带/一般 |

## 三、增强字段（能提取更好，不强制）

| 字段 | 说明 |
|------|------|
| 本息合计 | 本金+利息 |
| 抵押金额/是否最高额抵押 | 抵押登记金额上限 |
| 抵押顺位 | 第一/第二顺位 |
| 查封情况 | 首封/轮候/查封顺序 |
| 抵押物现状 | 已清场/已拍卖/租赁中/占用 |
| 额外查封物 | 除抵押物外的可执行财产 |
| 贷款行/批次/资产包 | 原始贷款机构/所属包 |
| 主债务人情况/保证人情况 | 经营/资产/涉诉描述 |
| 计息基准日/转让基准日 | 利息计算截止日 |

## 四、明确不采集/不展示（平台边界）

- ❌ 挂牌价/折扣率：非必备（AMC/个人招商标注"协商中"），不设必填
- ❌ 成本率/资金成本/费用估算：不算账
- ❌ 买入建议/利润测算：不做决策
- ❌ "差额继续追偿/超额退还"提示：从业者基本知识，不提醒

## 五、补充材料机制（触发报告重生成）

| 材料 | 更新版块 |
|------|---------|
| 判决书 | 本息计算（精确）、法律文书、债权基本信息 |
| 评估报告 | 抵押物估值 |
| 情况说明/实地信息 | 抵押物现状、清场难度 |
| 补充后 | 报告版本 +1，保留历史可回退 |

## 六、输入流程（技术文档 5.3 对照）

1. 三种输入：粘贴文本 / 上传 Excel / 勾选已有债权（列表三字段齐全才可勾）
2. 解析失败明确提示（"未找到债务人名称列"等），不静默
3. 预览表格 → 用户确认 → 启动尽调
4. 单次最多 5 条；单文件 ≤500 行 / ≤10MB
5. **文件指纹去重**（文件名+大小+lastModified），重复提示 + 一键清理
6. **格式白名单 + 魔数双重校验**（防伪装文件）
7. **description 缺失时自动补全**（基于结构化字段生成描述文本），仍缺的标"待补充"
8. 进度页 3 秒轮询、排队显示"当前第 N 位"、失败节点可重试、失败不自动跳转
9. 我的任务：状态筛选（全部/排队/进行/成功/失败）+ 失败重试
10. 用户标注：债权可标"未尽调/已尽调"，按用户维度存储
11. 债权对比字段：本金/抵押物类型/地区/司法状态/债务人状态/风险等级/信息完整度（挂牌价折扣率已去）

## 七、信息完整度（"待补充"标签）

- 🟢 完整：三核心字段 + 主要重要字段齐全
- 🟡 基本可用：三核心字段齐全，部分重要字段缺失 → 标"待补充"列出缺项
- 🔴 不完整：核心字段缺失 → 不可尽调，标"待补充"阻止勾选
- 用"待补充"标签，不用红色刺眼样式
