## 5. 启动方式

```bash
# 后端（backend 目录）
cd backend
.venv\Scripts\activate
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 前端已构建进 frontend/dist，后端自动服务；开发改前端需重新构建：
cd frontend
npm run build
```

浏览器访问：http://127.0.0.1:8000/
- 前台登录：普通用户（如 testuser/test123）
- 管理后台独立入口：http://127.0.0.1:8000/admin-login（admin/admin123456）

## 7. 踩坑与注意事项（接手必读）

1. **PDF 生成**：用 reportlab（纯 Python），**不要改回 WeasyPrint**（Windows 缺 GTK 无法运行，曾因此导致"已生成但无法下载"bug）。
2. **沙箱/权限**：本机开发时 `python.exe`/`npm` 启动可能被安全沙箱拦截，需授权运行；脚本文件用 UTF-8 且避免 `python -c` 内联中文（会 SyntaxError），一律写 `.py` 文件执行。
3. **报告页空白**：曾因 antd import 漏 `Input` 导致全站报告页白屏——修改 ReportPage 等页面时注意 import 完整性。章节渲染已有 SectionBoundary 错误边界保护。
4. **SQLite 迁移**：新增模型列时 `Base.metadata.create_all` 不会给已有表加列，需手动 `ALTER TABLE`（见历史迁移脚本模式）。
5. **报告/债权对应**：任务多选批量尽调时每债权独立生成报告；`source_claim_ids` 记录当次导入全量清单（含未勾选）。
6. **员工/用户分离**：editor/admin 角色仅用于后台管理，前台业务接口有中间件拦截；员工可查看用户报告但不能下载 PDF。
7. **土地价格库**：前台不展示，管理后台维护；估价引擎按「地区+土地性质」自动匹配（精确→市→省→全国逐级回退）。
8. **估值口径**：经济下行取档——商业取最低价、住宅/工业取中间值；成本法参数集中在 `land_factory_valuation.py` 顶部常量表。
9. **OCR 依赖链**：rapidocr → onnxruntime + opencv + numpy + shapely + pyclipper + pillow + pymupdf，恢复环境时务必成套安装。
10. **cpolar 演示**：外网演示用 cpolar 隧道（域名随重启变化），本地 uvicorn 和 cpolar 需保持运行。
