## 一、当前系统怎么处理"覆盖"（现状盘点）

### 1. 覆盖展示（七、抵押物分析）
- 公式：`主参考估值` vs `本息合计`（= 本金 + 利息，两数并列展示）
- 展示口径：只并列**两个数字**，不点评、不算覆盖率
- 提示语："抵押物主参考估值与本息合计并列展示，供参考；具体覆盖情况请结合专业评估判断"

### 2. 覆盖与评级联动（一、尽调结论摘要 / 十、风控评估）
- `_fallback_summary` 评级：`覆盖率 = neutral_cents（中间值） / 本息合计`
  - ≥150% → ★★★★★；100%~150% → ★★★★；70%~100% → ★★★；40%~70% → ★★；<40% → ★
- LLM 版评级 prompt：同样按 覆盖>150%→★★★★★ 等规则

### 3. 覆盖与处置方案联动
- 目前**没有联动**：处置方案（拍卖/以物抵债/其他）不引用覆盖率

### 4. 主参考值（reference_cents）取档现状（已核实代码）
- 工业（成本法）：`reference = 中间值(neut)`，label「主参考估值（工业类取中间值）」
- 商业/商铺/写字楼：`reference = 保守(最低价)`，label「主参考估值（商业类取最低价）」
- 住宅/别墅：`reference = 中间值`，label「主参考估值（住宅类取中间值）」
- ⚠️ 覆盖展示用 reference_cents，评级却用 neutral_cents（工业=reference 一致；**商业类两者不同**：展示用最低价、评级用中间值）

### 5. 评级覆盖率的另一处不一致（2026-08-26 补充核查）
- **降级版评级**（`_fallback_summary`）：固定用 `neutral_cents`（中间值）÷ 本息，分档给星
- **LLM 版评级**（prompt 第427行）：只写"抵押物覆盖>150%→★★★★★"，**没指定用哪档估值**——由 AI 自行判断（可能用中间值/主参考值/保守值，每次可能不同）
- → 同一份报告若走 LLM 评级，覆盖率口径不稳定；且两处与"展示口径(reference)"都不保证一致

### 6. 真实数据演示（report 4 芬得，本息1376万）
| 口径 | 估值 | 覆盖率 | 现行阈值星级 |
|---|---|---|---|
| 保守值 | 664.37万 | 48.3% | ★★ |
| 中性值 | 916.95万 | 66.6% | ★★ |
| 乐观值 | 1169.52万 | 85.0% | ★★★ |
| 主参考值 | 916.95万 | 66.6% | ★★ |

→ 同一笔债权，覆盖率在 48%~85% 之间摇摆，星级在 ★★~★★★ 之间波动——**口径不定，结论就不定**。这正是必须由用户定义统一口径的原因。

## 二、我发现的问题（很可能就是您说"没理解透"的地方）

| # | 问题 | 说明 |
|---|---|---|
| 1 | **口径不一致** | 展示用 `主参考估值`，评级用 `中间值(neutral)`——同一个"覆盖"两种口径，可能算出的数不一样 |
| 2 | **主参考值的取档规则** | 商业取最低价、工业/住宅取中间值——这是"保守还是中性"的口径，用户是否认可？ |
| 3 | **覆盖率用什么分子** | 到底该用：保守值？中间值？主参考值？还是拍卖预期价（含一拍70%/二拍再降20%的折价）？ |
| 4 | **分母是否含费用** | 覆盖的分母只是"本息合计"吗？还是要考虑：拍卖税费（10%~30%）、清场/腾退成本、评估费、利息续算等？ |
| 5 | **覆盖率阈值** | 现在 70%/100%/150% 分档是系统拍的，从业者实际怎么判"覆盖充足/不足"？ |
| 6 | **覆盖不足时的表述** | 报告现在只说"覆盖不足/有缺口"，是否应该给出"预计可受偿区间"或明确提示风险等级？ |
| 7 | **覆盖与处置方案联动** | 覆盖高 → 是否提示"优先走拍卖"？覆盖低 → 是否提示"以物抵债/深挖其他财产"？ |
| 8 | **多抵押物/多顺位** | 有多个抵押物或存在第二顺位、轮候查封时，覆盖率怎么算？ |

## 二·补、覆盖率分子（可变现价值）的修正因素（2026-08-26 用户传授，待纳入公式）

用户传授的三类抵押物知识，均影响"可变现价值"（覆盖率的分子），讨论时应纳入：

| 类型 | 修正因素 | 对可变现价值的影响 |
|---|---|---|
| 工业 | 土地性质（划拨地过户须补缴出让金及未缴费用）| 下调 |
| 工业 | 用地等级 M0/M1/M2/M3（M0最值钱→M3最差）| M0 上调、M3 大幅下调 |
| 住宅 | 唯一住房：满足条件可拍卖，但须提供安置住房或扣5-8年租金 + 清户腾退成本 | 下调（实际受偿率低于表面覆盖率）|
| 商业 | 地段与商业氛围（人流/商圈/出租率/产业支撑）| 大幅波动，需实地尽调修正 |

→ 待确认：覆盖率分子 = 基础估值（某档）×（1 - 处置成本率）？还是更简单的"基础估值 - 各项成本"？
